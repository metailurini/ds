# v0.38.0 Test Plan — Recursive Walk Helpers and DX Integration Cleanup

## Status

Planned. This test plan must be implemented with the `v0.38.0` production work
and then updated if the implementation deliberately amends the milestone spec.

## Purpose

`v0.38.0` adds a small recursive file-walk helper surface and closes the
`v0.34.0` through `v0.38.0` DX wave. The test suite must prove that:

1. `dir.walk*` helpers are useful for analyzer-style recursive source walking.
2. VM execution and standalone emitted Bash agree for accepted filesystem data.
3. Hidden-entry, symlink, ordering, duplicate, required-match, and extension
   rules are deterministic and documented.
4. Generated Bash stays standalone and helper-hygienic.
5. Current docs/examples no longer present solved DX-wave workarounds as open
   problems.

Do not add tests that imply a broader glob redesign, hidden traversal options,
symlink following, max-depth support, callbacks, metadata rows, or new syntax.

## Test suite location

Add the dedicated suite at:

```txt
tests/v0_38/run.sh
```

Wire it into the aggregate test targets in `Makefile` after `v0_37`.

The suite should be readable as both a feature test suite and a DX-wave cleanup
checklist. Prefer many focused fixtures over one large script.

## Required commands

At minimum, the implementation pass must run:

```sh
make
make test-v0-31
make test-v0-33
make test-v0-34
make test-v0-35
make test-v0-36
make test-v0-37
make test-v0-38
```

Also run when feasible:

```sh
make test
```

If the environment cannot run the full aggregate suite, record the exact failure
or timeout point and all focused suites that completed. Do not mark the version
complete with only documentation checks.

Run sanitizer or leak-check variants for the VM traversal code when the project
already exposes such targets or when a local manual build is practical. File
tree traversal must not leak directory handles or path buffers on error paths.

## Test conventions

The suite should provide helpers for:

- creating an isolated temporary workspace per case;
- creating directories, regular files, hidden entries, symlinks, and hostile file
  names;
- skipping symlink-specific assertions with a clear reason when the host does
  not support symlinks;
- running `ds check`, `ds hir`, and `ds bytecode` where kind/debug visibility is
  relevant;
- running VM execution and emitted Bash execution;
- checking stdout, stderr shape, and exit status parity;
- checking generated Bash with `bash -n`;
- asserting emitted Bash does not invoke `ds`;
- asserting helper definitions are included only when needed and are deduped;
- asserting loop bodies do not run after required-match failures;
- comparing sorted output bytewise under deterministic expectations;
- preserving exact file names with spaces, tabs, leading dashes, braces, quotes,
  dollars, semicolons, and newlines where the existing test harness can express
  them safely.

When a case checks VM/Bash parity, compare all deterministic outputs:

```txt
stdout
stderr shape, where deterministic
exit status
filesystem side effects, where deterministic
```

Use temporary directories outside the project tree so recursive walk tests do not
depend on the current checkout contents.

### 19. Edge-case matrix

Implementation review must explicitly cover this matrix. Prefer automated tests
for each row; when a case is host-dependent, record a skip reason.

| Case | Expected behavior |
| --- | --- |
| valid root, no files | non-bang returns empty array; bang fails |
| valid root, only directories | non-bang returns empty array; bang fails |
| missing root | runtime failure |
| root is file | runtime failure |
| unreadable root | runtime failure or host-dependent skip in test |
| hidden root explicitly named | accepted; nested hidden descendants skipped |
| hidden file under visible root | skipped |
| hidden directory under visible root | skipped and not traversed |
| directory symlink | not traversed |
| symlinked file | not returned under the strict v0.38 rule |
| broken symlink | ignored, not fatal |
| duplicate extensions | no duplicate output |
| empty extension array | static rejection when literal |
| dynamic empty extension | runtime data failure |
| extension without leading dot | rejection/failure |
| glob-like extension `*.c` | rejection with hint |
| extension with slash | rejection/failure |
| uppercase vs lowercase extension | bytewise exact match |
| names with spaces/tabs | preserved |
| names with leading dash | preserved |
| names with shell metacharacters | data only, no shell execution |
| names with newline | preserved or documented host/harness limitation |
| ambient locale changed | emitted Bash still deterministic |
| hostile `IFS` | emitted Bash still preserves path arrays |
